# Review Proof

External LLM review is expected for completed features and milestones when designated by the Tech Lead/project plan.

Proof requires:
- [ ] Reviewer and reviewed revision are recorded.
- [ ] Scope is explicit.
- [ ] Every substantive finding has severity and evidence.
- [ ] Implementer marks each substantive finding `ACCEPTED`, `REJECTED_WITH_REASONING`, or `ESCALATED_FOR_INVESTIGATION`.
- [ ] Accepted fixes are re-tested.
- [ ] Rejections contain technical reasoning/evidence rather than preference alone.
- [ ] Escalated scientific findings use authoritative evidence when resolved.
- [ ] No Critical or High finding remains unresolved.

LLM reviewer claims are signals to investigate, not scientific proof by themselves.

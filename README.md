# AI Spacecraft Delegation System

Repo-ready V1 scaffolding for the project's agentic engineering loop:

`Interview -> Playbook -> Toolbox -> Proof -> Review/Learning -> Playbook`

Copy these files into the root of the AI Spacecraft repository. Start with `CLAUDE.md` and `playbook/PLAYBOOK.md`.

This package intentionally contains delegation/process scaffolding rather than spacecraft implementation code.

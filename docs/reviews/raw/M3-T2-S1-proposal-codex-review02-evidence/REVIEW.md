No invalid mass reached the added powered context construction. Stage arrays are writable; mutations can poison subsequent RK4 stages. Safety comes from ordering: `mass` is computed once using float conversion and a built-in dry mass, and is a built-in float. `thrust_acceleration` validates that same immutable value before context construction. A later mutation of the underlying y/r/v cannot mutate this local float. Array subclasses can change earlier operations or raise earlier; they cannot invalidate this already validated local float. This argument assumes the production functions/classes have not themselves been monkeypatched and no external deliberate bypass of frozen spacecraft storage.

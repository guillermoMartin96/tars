# M2 approved reference snapshot (DR-0021 option A)

`REFERENCE_SNAPSHOT.json.gz` holds every reference-derived value of the M2 Proof and of the
GMAT M2 evaluation, recorded from a clean, reviewed implementation. The Proof, `gmat_m2.py
compare` and `run` verify their freshly computed references against it, value by value
(`tars.validation.reference_snapshot`). The coverage inventory, the exclusions, the
tolerance method and the measurements are in VAL-0015 (`docs/science/validation.md`).

Baseline 1: 48,279 records, 920,849 values. Before approval it passed `verify-baseline`
(snapshot DOP853 vs the committed GMAT rows: at most 4.66e-6 m and 5.39e-9 m/s; coast
energy and angular momentum conserved; anchors and extrema consistent), and the M2 Proof
and all three GMAT evaluations passed while recording. Agreement with this file is not
evidence of physical correctness; that rests on those checks.

## Changing the baseline (DR-0021 condition 3)
Never regenerated by tests, CI or the Proof. A new baseline is one reviewed change that:
1. generates a candidate from a clean tree:
   `uv run python toolbox/scripts/reference_snapshot.py generate --out runs/refsnap/candidate.json.gz`
   (it refuses to write this directory, and fails unless the Proof, the GMAT evaluations and
   `verify-baseline` pass);
2. compares it with this baseline:
   `uv run python toolbox/scripts/reference_snapshot.py compare <this file> <candidate>`;
3. copies it here, sets `APPROVED_REFERENCE_SNAPSHOT_SHA256`, adds a row above, and records
   the justification and the comparison in the commit message and the review record;
4. passes an independent (Codex) review before it is accepted.
